# Election Analyst 2026 - מיומנות ניתוח בחירות לכנסת 2026

מיומנות זו מנחה את סוכן Antigravity בביצוע ניתוח שבועי מקיף, אובייקטיבי ומבוסס ראיות של המפלגות והמועמדים המתמודדים בבחירות לכנסת ה-26.

## עקרונות פעולה מרכזיים
1. **חיפוש חי ואמין**: איסוף מידע ישיר ממקורות גלויים (אתרי מפלגות, מצעים, ראיונות, הצבעות בכנסת, רשתות חברתיות).
2. **חובת ציטוט וקישורים (Verifiable Citations)**: כל ציון וקביעה חייבים להישען על ציטוט, עובדה וקישור URL ישיר.
3. **סף מקומות ריאליים דינמי**: ניתוח מועמדים ברשימה עד רף המנדטים הממוצע בסקרים האחרונים + 1 (לפי `config/polls.yaml`).
4. **סולם ניקוד מנורמל**: מ-100- (התנגדות מלאה לעמדת המשתמש) ועד 100+ (התאמה מלאה).

## שלבי ביצוע שבועיים (Weekly Workflow Run)

### שלב 1: עדכון סקרים ורשימות
1. בדיקת סקרים חדשים שפורסמו בשבוע האחרון (כאן 11, חדשות 12, חדשות 14, מעריב וכו').
2. עדכון קובץ `config/polls.yaml`:
   - ממוצע מנדטים עדכני לכל מפלגה.
   - עדכון סף המקומות הריאליים (`realistic_cutoff = round(poll_average) + 1`).
   - הכללת כל מפלגה שעוברת את אחוז החסימה (3.25% / 4 מנדטים) לפחות בסקר אחד.
3. עדכון `config/parties.yaml` אם חלו שינויים בראשי מפלגות, איחודים או מועמדים ריאליים.

### שלב 2: קריאת פרופיל הנושאים
1. קריאת `config/profiles/default.yaml` (או פרופיל חלופי שהוגדר ע"י המשתמש).
2. לכל אחד מ-9 הנושאים:
   - זיהוי העמדה הרצויה של המשתמש.
   - בדיקת תת-הנושאים כרשימת תיוג (Rubric).

### שלב 3: ביצוע המחקר והניתוח (Live Web Research)
עבור כל מפלגה וכל נושא, הסוכן מבצע חיפושים ממוקדים ומעריך את 6 הקריטריונים:
1. **מצע המפלגה (15%)**: האם קיים מצע רשמי? כיצד הוא מתייחס לנושא?
2. **אמירות וכתיבה של ראש המפלגה (15%)**: מה אמר בראיונות/נאומים/רשתות? האם תואם מצע?
3. **ניסיון מעשי ופעילות ראש המפלגה (30%)**: מה הרקע המעשי, האקדמי והניהולי? כיצד פעל והצביע בפועל? האם שינה עמדות?
4. **אמירות וכתיבה של מועמדים ריאליים (10%)**: מה עמדות המועמדים בטווח המקומות הריאליים?
5. **ניסיון מעשי ופעילות של מועמדים ריאליים (20%)**: מה הרקורד המקצועי/חקיקתי של המועמדים הריאליים בתחום?
6. **מועמד ריאלי ייעודי לתפקיד ביצועי (20%)**: האם יש מועמד מובהק המיועד לתיק/תפקיד הרלוונטי והאם עמדתו תואמת את הרצוי?

*עיין במדריך המלא:* [מחוון הקריטריונים](./references/criteria_rubric.md)

### שלב 4: הרצת מנוע החישוב והפקת הדוחות
1. יצירת קובץ הנתונים הגולמי: `data/evaluations/YYYY-MM-DD.json`.
2. הרצת סקריפט החישוב וההפקה:
   ```bash
   python3 scripts/run_analysis.py --date YYYY-MM-DD
   ```
3. הסקריפט יפיק אוטומטית:
   - קובץ Markdown מפורט: `reports/YYYY-MM-DD/report.md`.
   - אתר אינטראקטיבי מעודכן ל-GitHub Pages: `docs/index.html`.

### שלב 5: הצגת סיכום למשתמש
הצגת לוח המובילים (Leaderboard), מגמות עיקריות, נקודות מפתח וקישור לדוח המלא.
