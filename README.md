# מערכת אנליזה רב-סוכנית: בחירות לכנסת ה-26 (2026) 🇮🇱

מערכת חכמה, אובייקטיבית ומבוססת ראיות לניתוח מפלגות, ראשי מפלגות ומועמדים במקומות ריאליים לקראת הבחירות לכנסת ה-26.  
המערכת מבוססת על ארכיטקטורת רב-סוכנים מקבילית ומפרידה בצורה מלאה בין **מאגר מידע סטטי** לבין **נתונים והערכות דינמיות מרובות-פרופילים**.

🌐 **דשבורד אינטראקטיבי פעיל ב-GitHub Pages**:  
**[https://vvainer.github.io/elections-il-2026/](https://vvainer.github.io/elections-il-2026/)**

📐 **ארכיטקטורת המערכת והחלטות תכנון (ADRs)**:  
**[ARCHITECTURE.md](ARCHITECTURE.md)** — מסמך הארכיטקטורה הקנוני, תרשימי זרימה ויומן החלטות ארכיטקטוניות (ADR-001 עד ADR-007).

## 🛠️ מיומנויות Antigravity (Skills)

המערכת מופעלת באמצעות 4 מיומנויות ייעודיות:

1. **`run-election-round`** (`.agents/skills/run-election-round/SKILL.md`):  
   מיומנות ההרצה המרכזית. מפעילה סבב רב-סוכנים מלא ב-4 שלבים (9 סוכני איסוף מקביליים, אימות צולב דו-שלבי, מיזוג והערכת כלל פרופילי המשתמש, ואימות UI מחמיר עם תצלומי מסך לפני פריסה).
2. **`build-static-kb`** (`.agents/skills/build-static-kb/SKILL.md`):  
   מיומנות איסוף וניהול מאגר המידע הסטטי. מפעילה סוכני מחקר ייעודיים לבניית רשימות מועמדים מלאות (1..30+), קורות חיים, הצבעות היסטוריות, הישגים וכישלונות, ומצעי מפלגות רשמיים.
3. **`interview-worldview`** (`.agents/skills/interview-worldview/SKILL.md`):  
   מיומנות ראיון אינטראקטיבית המאפשרת למשתמש להגדיר עולם ערכים מותאם אישית (משקולות, עמדות רצויות וסדרי עדיפויות) באמצעות `ask_question`, ושומרת פרופיל חדש ב-`config/profiles/<profile_name>.yaml`.
4. **`election-analyst`** (`.agents/skills/election-analyst/SKILL.md`):  
   מתודולוגיית הניתוח, מחוון 6 הקריטריונים המנורמלים, והנחיות התפקיד לסוכני המשנה.

## 🏛️ ארכיטקטורת מידע: סטטי מול דינמי

כל הנתונים הפוליטיים וההערכות נשמרים אך ורק בארטיפקטים מודולריים הניתנים לבנייה מחדש (ולא במסמכי המערכת):

### מאגר מידע סטטי (`data/static/`)
* **קטלוג 9 נושאי המדיניות**: מוגדר ב-`data/static/topics/catalog.json`.
* **מחוון ששת הקריטריונים**: מוגדר ב-`data/static/rubric/criteria.json` (סולם ציונים מ-`100-` עד `100+`, משקולות מנורמלות מ-110% ל-100%).
* **מאגר מפלגות ומועמדים** (`data/static/parties/<party_id>/`):
  - `party.json`: פרטים מזהים, אתר רשמי, קישור לסיעה בכנסת.
  - `candidates.json`: רשימת מועמדים מלאה (1..30+), השכלה, רקורד ציבורי, הצבעות מפתח, הישגים ומחלוקות.
  - `manifesto.md`: מצע המפלגה ועקרונותיה הרשמיים.

### נתונים דינמיים והערכות שבועיות
* **סקרים ומנדטים**: מעקב ממוצע סקרים ורף מועמדים ריאליים (`config/polls.yaml`).
* **עולמות ערכים / פרופילי משתמש**: קובצי קונפיגורציה ב-`config/profiles/*.yaml` (למשל פרופיל ברירת מחדל, פרופיל שוק חופשי, ופרופילים שנוצרו בראיון).
* **איסוף דינמי שבועי**: הצהרות, ראיונות ומקורות מאומתים מתוך סבב המחקר (`data/staging/`, `data/validated/`).
* **דוחות ודשבורד**: דוחות Markdown לכל פרופיל (`reports/YYYY-MM-DD/`) ודשבורד חי עם בורר פרופילים אינטראקטיבי (`docs/index.html`).

## 🚀 פקודות שימוש מהירות

### 1. הרצת סבב אנליזה מלא (Multi-Agent Lifecycle)
בצ'אט Antigravity:
```text
הרץ סבב רב-סוכנים מלא לבחירות 2026
```
*(המערכת תפעיל את המיומנות `run-election-round`)*

### 2. בנייה ואימות של מאגר המידע הסטטי
```bash
# בדיקת תקינות המאגר הסטטי
python3 scripts/build_static_kb.py --verify

# בנייה מחדש וסנכרון מלא
python3 scripts/build_static_kb.py --build-all
```

### 3. ראיון להגדרת עולם ערכים חדש
בצ'אט Antigravity:
```text
ראיין אותי להגדרת עולם ערכים חדש
```
*(המערכת תפעיל את המיומנות `interview-worldview` ותשאל אותך שאלות מובנות)*

### 4. הרצת צינור העיבוד המלא (Orchestrator)
```bash
# הרצה מלאה (אימות קישורים, מיזוג, הערכת כל הפרופילים, ואימות UI)
python3 scripts/orchestrate_analysis.py --date 2026-09-12 --stage all
```
